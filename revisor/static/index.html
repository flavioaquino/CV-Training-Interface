          Como usar

          Navegação
          EnterSalvar (marca como revisada) e ir para a próxima
          D / →Próxima imagem (salva se você alterou algo)
          A / ←Imagem anterior (salva se você alterou algo)
          Ctrl+SSalvar sem sair da imagem
          Caixas
          arrastar no vazioDesenhar caixa nova com a classe ativa
          Shift + arrastarDesenha uma caixa nova mesmo em cima de outra (ignora as existentes)
          clicar numa caixaSelecionar (a menor caixa sob o cursor ganha)
          Ctrl+C / Ctrl+VCopiar e colar. Com caixa selecionada, copia só ela; sem seleção, copia as visíveis. A colagem vale em outra imagem e cada uma desloca um pouco
          arrastar a caixa / as alçasMover / redimensionar
          TabSelecionar a próxima caixa
          1…0, Q, W, E…Com caixa selecionada: troca a classe dela. Sem seleção: escolhe a classe ativa
          Del / BackspaceApagar a caixa selecionada
          EscTirar a seleção
          Ctrl+ZDesfazer
          Visualização
          roda do mouseZoom no ponto do cursor
          botão direito / Espaço + arrastarMover a imagem
          FEncaixar a imagem na tela
          HEsconder/mostrar todas as caixas
          LEsconder/mostrar os nomes das caixas
          Limiar de confiança
          limiar geral / por classeEsconde (ou marca) sugestões abaixo do valor. Caixas ✓ do backend nunca somem
          Aplicar limiar nesta imagemApaga de vez as sugestões escondidas; use Ctrl+Z se errou
          Legenda
          ✓ linha grossaCaixa confirmada pelo backend
          linha tracejadaSugestão abaixo do limiar atual (ainda visível se "esconder" estiver desligado)
          número após o nomeConfiança da sugestão (some quando você edita a caixa)
